# DCBS
Dynamic Card Builder Studio

<hr />

## 🇧🇷
  é uma ferramenta web interativa para criar e personalizar cartões de apresentação (como cartões de visita ou perfis) em tempo real. Você pode ajustar cores, fontes, bordas, imagens de avatar e muito mais através de um painel visual, exportar o resultado como JSON, PNG ou imprimir/gerar PDF.
  
<hr/>

### 🇺🇸
  is an interactive web tool for creating and customizing presentation cards (like business cards or profiles) in real-time. You can adjust colors, fonts, borders, avatar images, and more through a visual panel, and export the result as JSON, PNG, or print/save as PDF.
